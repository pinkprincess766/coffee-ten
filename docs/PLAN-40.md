# План 40 PR — coffee-ten

Запрос Никиты в группе «Наука»: «штук 40 pr сделайте для coffee-ten». Это план из 40
маленьких независимых PR (P1–P40) поверх текущего `main` (после #193). Каждый пункт
привязан к конкретному коду или документу; «наполнителей» нет: если при работе пункт
оказывается пустым (уже сделано), он закрывается без PR с пометкой в этом файле.

Владельцы: **Вера** — код и тесты; **Ника** — документация, CI и ревью всех PR.
С 24.10 мерж — после ревью Ники и зелёного CI. «Ок» Никиты нужен для новых зависимостей,
замеров на Маке и отклонений от протокола.

## Общие ограничения (для всех P)

- Автор и коммиттер — `Cursor Agent <cursoragent@cursor.com>`, без `Co-authored-by`.
- Каждый PR от свежего `main`, без цепочек; если зависимость неизбежна — это сказано в PR.
- Никаких новых зависимостей: `Cargo.toml`, `Cargo.lock`, `pyproject.toml` не меняются.
- Порядок сложений не меняется; эталонные результаты совпадают бит в бит.
- Случайный поиск остаётся базовой линией; без фильтрации кандидатов моделью, ранней
  остановки и подгонки аналитической модели.
- Хэш пространства расписаний по умолчанию и базовая выборка при том же seed не меняются.
- Перед пушем: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`,
  `cargo test --workspace --locked`, плюс Python-тесты, если PR их касается. В PR честно
  написано, что запускалось.

Шестая пачка кода (после P21–P25) занята пунктами V1–V5; P26–P30 сдвигаются на следующую
пачку. Номера P не меняются, чтобы не ломать ссылки в слитых PR; V-пункты в 40 не входят
сверх плана, а заменяют пачку. Условие Ники для V1–V4: все логи `bench/results/`

- **V1** — метаданные записи: `commit`, `date` (строка), `dirty` (bool/null),
  `order_class` (preserving/reordering), `group` (naive/random/model/local/final; у naive

- **V2** — закрытые наборы полей: лишние поля записи, раунда и `reference_compilation`.
- **V3** — пустые строки между записями — ошибка с номером строки, как в `validate.py`.
- **V4** — peak-строки проверяются, а не пропускаются.
- **V5** — Python API: `numpy.ma.MaskedArray` на входе `run()`/`Kernel` — `TypeError`
  вместо тихого игнорирования маски.
- Позже, только с «ок» Никиты: формат `source_hash`/`space_hash` и `harness_profile`
  (касается ключа протокола).

### P1 — полнота ключа протокола (Вера)
- Цель: два лога без, например, `source_hash` не должны сравниваться (замечание Ники к `report.rs`).
- Изменение: явные списки обязательных полей = ровно то, что пишет `ProtocolKey::to_json`; неизвестные поля отклоняются; ошибка называет поле.
- Приёмка: тест удаляет каждое из 23 полей фикстуры из обоих логов — отказ с именем поля; юнит-тест сверяет валидатор с выводом писателя для V1/V2.
- Ограничения: формат лога и версия протокола не меняются.

### P2 — дрейф «не оценён» (Вера)
- Цель: не выдавать `false` за проверку, которой не было (`drifted` требует ≥ 10 раундов).
- Изменение: колонка Drift в обеих таблицах печатает `not evaluated`.
- Приёмка: 3 и 9 раундов → `not evaluated`; 10 ровных → `false`; 10 со скачком → `true`; golden обновлён.
- Ограничения: только отображение; флаг `drift` в JSONL и его проверка не меняются.
- После #194 сохранённый `bench/results/2026-11-07-n20-v1-n256.report.md` устарел в колонке
  Drift (там `false` вместо `not evaluated`). Перегенерировать его — только с «ок» Никиты.

### P3 — JSON/JSONL-ридер (Вера)
- Цель: закрепить поведение на CRLF, пустых строках, обрезанной последней записи, BOM, склеенных записях.
- Изменение: тесты `json.rs` и `tests/report_jsonl.rs`; сообщения `expected one JSON object per line`, `kind: expected string`.
- Приёмка: принимаемые/отклоняемые входы те же, что на `main`.
- Ограничения: BOM по-прежнему отклоняется.

### P4 — краевые случаи статистики (Вера)
- Цель: 0/1 раунд, нулевые и NaN/∞ замеры либо считаются точно, либо отклоняются с номером раунда.
- Изменение: тесты `tests/report_rounds.rs`, `stats.rs`; сообщения с номером раунда и именем поля.
- Приёмка: набор принимаемых входов не меняется.
- Ограничения: `replay.rs` — отдельно (P6).

### P5 — несовпадающие ключи (Вера)
